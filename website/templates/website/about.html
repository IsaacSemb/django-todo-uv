About This Project

This todo application is a learning project designed to explore Django's powerful features and understand full-stack web development.

Learning Goals

This project covers multiple approaches to building web applications:

  • Django ORM models, migrations, and database relationships
  • Traditional Django views and templates
  • Django REST Framework for API development
  • Modern development tools like uv for package management
